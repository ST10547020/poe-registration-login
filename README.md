\# PoE Registration and Login (Part 1)



Console-based Java application for user registration and login, built with Maven

and tested with JUnit 5, as part of the Programming 1A PoE (PROG5121).



\## Features



\- \*\*Registration\*\*: validates username (must contain an underscore and be no

&#x20; more than 5 characters), password (minimum 8 characters, at least one capital

&#x20; letter, one number, and one special character), and South African cell phone

&#x20; number (must include the international country code).

\- \*\*Login\*\*: verifies the entered username and password against the registered

&#x20; details and returns an appropriate welcome or error message.



\## Technologies



\- Java 21

\- Maven

\- JUnit 5
